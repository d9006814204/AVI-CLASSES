AVI CLASSES – FINAL UPDATE (14 NOVEMBER 2026)

इस अपडेट में पहले के UI बदलाव और Course/Test Series के one-time payment lock system को शामिल किया गया है।

1. Student Dashboard sidebar से Practice menu हटाया गया है। Practice feature/प्रश्न डेटा को delete नहीं किया गया।
2. Student-facing templates में Print button नहीं रखा गया है।
3. Registration/Login free है। केवल Login करने से कोई Paid Course या Paid Test Series unlock नहीं होती।
4. Admin द्वारा Courses category में प्रकाशित Paid LearningItem पर Buy Now दिखता है। Price item के `price` field से server-side पढ़ी जाती है।
5. Test Series के लिए ₹29 का Razorpay Order बनता है।
6. Razorpay signature, order amount, payment amount, order mapping और captured status server पर verify होने के बाद ही Purchase status paid होता है।
7. Paid Course सफल भुगतान के बाद CourseEnrollment बनाकर My Courses में जोड़ा जाता है। Direct file access भी purchase check से सुरक्षित है।
8. खरीदी हुई Test Series My Test Series और Dashboard में दिखाई देती है। बिना खरीद Test Series प्रश्न/टेस्ट शुरू नहीं किए जा सकते।
9. Admin Dashboard में Payment Records पेज जोड़ा गया है।
10. Database में additive `purchase` table जोड़ी गई है। Existing User, Question, Attempt, LearningItem और पुराने database records delete नहीं किए गए।

DEPLOYMENT NOTES
- Render में मौजूदा RAZORPAY_KEY_ID और RAZORPAY_KEY_SECRET TEST keys रखें।
- Webhook के लिए RAZORPAY_WEBHOOK_SECRET सेट करें और `/webhooks/razorpay` पर payment.captured event configure करें।
- Razorpay में Automatic Capture सक्षम रखें, क्योंकि unlock के लिए captured payment आवश्यक है।
- Course बनाने/अपलोड करने के लिए Admin → Learning Content Manager → Category `courses` चुनें और Price में 199 या ₹199 जैसे मान डालें।
- GitHub पर secrets कभी commit न करें।
- पहले TEST MODE में एक Student से Course और Test Series दोनों खरीदकर परीक्षण करें।
